# Botte v2

Этот проект представляет собой аналог контроллера Bodas (Bosch Rexroth) для управления барабаном бетономешалки (миксера). Проект реализован на базе платформы Arduino Nano. Управление осуществляется с помощью кнопок, а обратная связь обеспечивается датчиком Холла, который считывает обороты вала.

Контроллер предназначен для управления функциями вращения бетономешалки (загрузка/выгрузка, акселератор и деселератор). Несмотря на наличие документации на комплексные насосные установки (такие как CIFA MK32L, совмещающие свойства миксера и бетононасоса), данный проект фокусируется исключительно на аппаратном замещении контроллера Bodas для функции бетономешалки.

## Логика работы и основные возможности

### 1. Управление вращением (кнопки INC / DEC)
- **Плавный старт и разгон:** При нажатии кнопки увеличения (**INC**) контроллер включает реле `RIGHT` (Загрузка) и устанавливает стартовый ШИМ (значение 38). При удержании кнопки контроллер плавно наращивает ШИМ с заданным шагом.
- **Реверс:** При удержании кнопки уменьшения (**DEC**) происходит зеркальная операция — включается реле `LEFT` (Выгрузка). 
- **Плавное торможение при смене направления:** Если барабан вращается в одну сторону (например, Влево при нажатии DEC), а оператор нажимает INC (Вправо), контроллер сначала плавно снижает текущий ШИМ до нуля, отключает реле направления, и только затем включает противоположное вращение.

### 2. Защита по срыву оборотов (Safety)
Система постоянно мониторит обороты вала с помощью датчика Холла (измерение через внешнее прерывание):
- Если задан рабочий ШИМ (`pwm_setpoint > 0`), но обороты падают ниже **200 RPM**, система фиксирует аварию (взводится флаг `alert_hall`).
- В аварийном режиме сбрасываются целевые значения ШИМ.
- Фактический ШИМ плавно, без гидравлических рывков, опускается до нуля (через компенсационный таймер `tmr3`), после чего реле отключаются.
- Индикаторный светодиод (`IndicatorLed`) начинает непрерывно мигать, информируя об ошибке.

### 3. Режимы загрузки и выгрузки (Автоматическая компенсация ШИМ)
Данный алгоритм имеет два кардинально разных режима работы в зависимости от направления вращения:

**Режим Загрузки / Перемешивания (вращение Вправо):**
При штатной загрузке и заданном ШИМ <= 128 работает алгоритм поддержания постоянных оборотов барабана:
- Функция `ratio_comens` высчитывает коэффициент в диапазоне оборотов от 600 до 2500 RPM.
- Итоговый выходной ШИМ пересчитывается динамически с учётом оборотов двигателя машины. Компенсация обеспечивает необходимое давление для поддержания момента.
- **Демпфирование (сглаживание):** Значение ШИМ не отправляется на клапан напрямую. Вместо этого переменная `comensPWM` "догоняет" целевой ШИМ с шагом `pwm_step` каждые 40 мс, предотвращая резкие скачки давления в гидросистеме.

**Режим Выгрузки (вращение Влево):**
- При активации режима выгрузки (`left_flag == 1` через кнопку DEC) **автоматическая компенсация ШИМ отключается**.
- При выгрузке бетона неконтролируемые рывки скорости могут быть опасны при подаче готовой смеси. Поэтому система напрямую (в режиме прямой трансляции) передает заданное значение ШИМ (с учетом демпфера `comensPWM`) на гидроаппаратуру, игнорируя падающие или возрастающие обороты шасси автобетононасоса.

### 4. Мгновенная остановка
Кнопка **STOP** немедленно сбрасывает целевой и фактический ШИМ до нуля, отключает оба реле направления и сбрасывает все флаги вращения.

## Оборудование (Пины)

Все настройки пинов заданы в `src/main.cpp`:

- **D2 (`HallD`):** Подключение датчика Холла (используется внешнее прерывание).
- **D3 (`OUTPUT_PWM`):** Выход ШИМ для управления скоростью двигателя.
- **D4 (`OUTPUT_LEFT`):** Выход управления "влево" / выгрузка.
- **D5 (`OUTPUT_RIGHT`):** Выход управления "вправо" / загрузка.
- **D6 (`IndicatorLed`):** Индикаторный светодиод, используемый для отображения статуса и ошибок.
- **D7 (`BUTTON_INC`):** Кнопка увеличения ШИМ.
- **D8 (`BUTTON_DEC`):** Кнопка уменьшения ШИМ.
- **D9 (`BUTTON_STOP`):** Кнопка остановки.

## Зависимости

Проект использует следующие библиотеки (указаны в `platformio.ini`):
- `gyverlibs/uButton@^1.1.2` - Удобная обработка нажатий и удержаний кнопок.
- `gyverlibs/GTimer@^1.1.1` - Неблокирующие таймеры для выполнения периодических задач.
- `gyverlibs/GyverFilters@^3.2` - (Присутствует в зависимостях, возможно используется внутри кастомных библиотек или для подавления дребезга/сглаживания значений).

Также используется локальный заголовочный файл `freqmeter.h` для работы с датчиком.

## Сборка и прошивка

Проект настроен для сборки через [PlatformIO](https://platformio.org/).

Платформа: `Arduino Nano` (ATmega328, `nanoatmega328new`)

Команды PlatformIO:
```bash
# Сборка
pio run

# Загрузка прошивки (проверьте порт подключения, при необходимости пропишите upload_port в platformio.ini)
pio run -t upload

# Просмотр логов в Serial Monitor (скорость 115200)
pio device monitor -b 115200
```
