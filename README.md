# Botte v2

Этот проект представляет собой аналог контроллера Bodas Rexroth для бетономешалки. Проект реализован на базе платформы Arduino Nano. Управление осуществляется с помощью кнопок, а обратная связь обеспечивается датчиком Холла, который считывает обороты вала.

## Основные возможности

- **Управление ШИМ (PWM):** Плавная регулировка скорости двигателя с помощью кнопок увеличения (INC) и уменьшения (DEC).
- **Направление вращения:** Управление реле для загрузки (RIGHT) и выгрузки (LEFT).
- **Остановка:** Кнопка STOP сбрасывает ШИМ в ноль и останавливает двигатель.
- **Измерение оборотов:** Использование датчика Холла для измерения текущих оборотов двигателя (RPM).
- **Защита по срыву оборотов:** Если двигатель должен работать (ШИМ > 0), но обороты падают ниже 200 RPM, система фиксирует ошибку, плавно сбрасывает ШИМ и начинает мигать индикатором.
- **Компенсация ШИМ:** Алгоритм компенсации в зависимости от оборотов, позволяющий поддерживать необходимую мощность в заданном диапазоне.

## Оборудование (Пины)

Все настройки пинов заданы в `src/main.cpp`:

- **D2 (`HallD`):** Подключение датчика Холла (используется внешнее прерывание).
- **D3 (`OUTPUT_PWM`):** Выход ШИМ для управления скоростью двигателя.
- **D4 (`OUTPUT_LEFT`):** Выход управления "влево" / выгрузка.
- **D5 (`OUTPUT_RIGHT`):** Выход управления "вправо" / загрузка.
- **D6 (`IndicatorLed`):** Индикаторный светодиод, используемый для отображения статуса и ошибок.
- **D7 (`BUTTON_INC`):** Кнопка увеличения ШИМ.
- **D8 (`BUTTON_DEC`):** Кнопка уменьшения ШИМ.
- **D9 (`BUTTON_STOP`):** Кнопка остановки.

## Зависимости

Проект использует следующие библиотеки (указаны в `platformio.ini`):
- `gyverlibs/uButton@^1.1.2` - Удобная обработка нажатий и удержаний кнопок.
- `gyverlibs/GTimer@^1.1.1` - Неблокирующие таймеры для выполнения периодических задач.
- `gyverlibs/GyverFilters@^3.2` - (Присутствует в зависимостях, возможно используется внутри кастомных библиотек или для подавления дребезга/сглаживания значений).

Также используется локальный заголовочный файл `freqmeter.h` для работы с датчиком.

## Сборка и прошивка

Проект настроен для сборки через [PlatformIO](https://platformio.org/).

Платформа: `Arduino Nano` (ATmega328, `nanoatmega328new`)

Команды PlatformIO:
```bash
# Сборка
pio run

# Загрузка прошивки (проверьте порт подключения, при необходимости пропишите upload_port в platformio.ini)
pio run -t upload

# Просмотр логов в Serial Monitor (скорость 115200)
pio device monitor -b 115200
```
